## 📌 Sobre o Projeto
O objetivo deste projeto é ajudar os usuários a estimarem o consumo mensal de energia elétrica de seus eletrodomésticos, além de apresentar um cálculo do custo financeiro estimado com base no tempo de uso diário.

## 🧮 Fórmula Utilizada
O consumo mensal em quilowatts-hora (kWh) é calculado pela seguinte fórmula:

$$\text{consumoMensal} = \frac{\text{potencia (W)} \times \text{horasDia} \times 30}{1000}$$
